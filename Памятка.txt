В скрипте на создание таблиц и вставка данных уже выполнено задание по импорту. Поэтому для импорта см. видео.

Не забывайте USE [Mol]
Где вместо [Mol] вставляете своё название базы данных.

Это свойство в скрипте - приращение ID по одному, то есть счетчик. Не обязательное свойство.

[int] IDENTITY(1,1)

Как работает SQL-скрипт? 
JOIN-ы: Связываем таблицы заказов, покупателей, продукции, спецификаций и материалов, чтобы получить полный контекст по каждой позиции.

s.NormConsumption * m.Cost: Вычисляет стоимость материалов, необходимую для производства 1 единицы продукции. NormConsumption — это норма расхода материала на 1 единицу продукта, m.Cost — текущая цена материала.

SUM(...): Суммирует затраты по всем материалам, входящим в состав продукта (т.к. на 1 продукт может приходиться несколько строк в Specifications).

o.Quantity * ...: Умножает себестоимость единицы продукции на фактическое количество в заказе.
ROUND(..., 2): Округляет итог до 2 знаков после запятой (стандарт для валюты).


В приложении не забывайте менять строку подключения, иначе работать не будет


ВАЖНО! Если будете "заводить" приложение на своём ПК используйте скрипт для создания таблицы USERS из папки с приложением. Старую таблицу при этом можно удалить.
